Coding challenge · Regulatory Radar

Which rules need attention first, for my country and my sectors?

Self-hosted radar for chambers and associations: EU and national channels in any language, one entry per procedure, ranked by actionability.

One command

docker compose up; offline by default, Postgres as the only state.

5-phase pipeline

Ingest → translate → embed → group → classify.

Measured

Two label sets, offline and online (OpenAI, Mistral).

Research

A common interface for every source

SourceAdapter

fetch(since) streams batches with a watermark; normalize(record) is pure. Seed file and live sources are the same to the pipeline.

Common schema

ISO 3166-1 country, ISO 639-1 language, ISO 8601 dates, reference key, action points (deadline, vote, standstill, adoption).

Raw first

Payload stored verbatim (JSONB), SHA-256 dedup; invalid records kept raw and listed as rejected.

Status

Each pass ends ok, degraded (a failed day holds the watermark back) or failed, with item count and last fetch.

Standards

NACE Rev. 2.1 only

Current revision

1,047 codes plus Eurostat explanatory notes; embedded once per model for semantic search.

Rev. 2 mapped at the edge

Seed tags and example profiles use Rev. 2. Eurostat's correspondence maps them once: G47 → G47.1–G47.7, G47.9, J60.39. Not 1:1, a little broader by design.

Hierarchical match

Labels stored as ltree paths (NACE.C.C24.C24_4): selecting C, C24 or C24.4 is one GiST-indexed query.

Stateless worker

Each phase reads pending rows from Postgres and appends results with an engine id; failures retry after 1, then 5 min.

Offline

Phases 2–3 skipped; grouping by refs only; relevance from a multilingual concept lexicon.

Online

One provider (Mistral or OpenAI) for chat, embeddings and web search; its own database.

The agents

Instructions and tools, checked in code

Grouping

  • Instructions: what is and is not the same procedure, with examples
  • Input: identifiers (CELEX, procedure, TRIS, ELI) and pre-computed candidates
  • Code guard: join only with high confidence, same jurisdiction

Classification

  • Instructions: who carries the duty along the value chain, size thresholds, keyword traps
  • Code guard: unknown codes and titles sent back; skipped rule sectors added as borderline
  • 2 runs, a third on a tie, majority decides

Tools

Embedding neighbours, full-text search, read-only SQL, web_search, fetch_url, search_nace, nace_notes.

Underneath

Matching country × NACE in one indexed query

Labels, not profiles

One row per group × country × NACE code; EU groups get all 27 countries. The profile only filters.

NACE hierarchy

C24 → NACE.C.C24.* + NACE.C + NACE: own branch up and down, never siblings.

Fast reads

Materialized views refreshed after each cycle; GiST on (country, nace_path); scope, match, rank and page in one SQL query.

Underneath

How the list is ordered

Open window Upcoming vote Standstill In procedure Adopted Information

radar_actionability()

One immutable SQL function picks the tier; windows, votes and standstills count only if their date is on or after as_of.

Tie-breaks

Action date (soonest), verdict (relevant first), latest publication, group key. Same input, same output.

In the UI

API order unchanged; relevant + borderline by default; NEW since the last "Mark all as seen".

Trade-offs

The interesting decisions

QuestionDecision
Threshold?Recall first: show relevant + borderline; stated tags are always relevant.
Can an LLM remove an item?No. It adds and ranks; a pair relevant once stays tracked.
Same procedure?Shared ref or reaction (deterministic), plus agent joins with stored rationale.
Reproducible?Results stored with engine id and reused; ranking is pure SQL.
Operator data?Never sent: classification is profile-independent. EU-only inference via Mistral's EU endpoint, without web search.
Slow source?Timeouts and bounded backoff; the run shows degraded.
